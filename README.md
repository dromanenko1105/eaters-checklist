# Eaters — система контроля смен

Офлайн-система для контроля работы менеджера ресторана «Нео-бистро Eaters».

## Что внутри

- `index.html` — стартовая страница с двумя кнопками
- `app/manager-checklist.html` — приложение менеджера
- `app/owner-dashboard.html` — дашборд владельца

## Как работает

1. Менеджер открывает приложение менеджера.
2. Заполняет чек-лист, фото, отзывы и выручку.
3. Нажимает **Сформировать отчет**.
4. Нажимает **Скачать JSON отчет**.
5. Отправляет JSON-файл руководителю.
6. Руководитель открывает дашборд.
7. Загружает JSON-файл.
8. Дашборд показывает KPI, рейтинг, выручку, фото и AI-анализ.

## Важно

- Сервер не нужен.
- Telegram не нужен.
- API не нужен.
- Все работает локально в браузере.
- Данные сохраняются в браузере через localStorage.
